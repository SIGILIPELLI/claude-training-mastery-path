# Claude Training Mastery Path

A structured, module-wise training program that takes you from "what is
Claude and how do I write a decent prompt" to designing organization-wide AI
adoption plans — with worked prompt examples and practical frameworks in
every module.

This track is **not** about Anthropic's internal engineering or model
internals — it's about the practical craft of using Claude well: prompting,
structuring conversations, working with documents, verifying outputs, and
building repeatable, responsible workflows around an AI assistant.

This is an independent educational resource created by an outside educator.
It is not produced, endorsed, or reviewed by Anthropic. Claude's specific
capabilities, models, and pricing change over time — for anything precise,
always check the current [Claude documentation](https://docs.claude.com/).

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | What Claude is, writing effective prompts, structuring conversations, core use cases | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Advanced prompting, structured outputs, brainstorming, fact-checking workflows | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | Context management, multi-step workflows, team usage, privacy considerations | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Organizational AI literacy, governance, training others, career growth | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules build on earlier ones.
- Every topic page includes concrete before/after prompt examples, a worked
  scenario, and a cheat-sheet table you can reuse directly.
- Each topic ends with a practical **Exercise** — a deliverable you actually
  write, not a quiz.
- Each level ends with a project that combines everything learned in that
  level into a single real artifact.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)

## What you'll need

No software, no subscriptions beyond access to Claude itself (claude.ai, the
Claude apps, or however you already access it) — just a document editor to
write the exercises in. Every framework in this course is presented as a
table or template you can copy directly into your own notes.

🎥 **Prefer video?** Watch the [Mastery Path video series](https://youtube.com/@sigilipelli) on YouTube — Shorts and full walkthroughs of these lessons.
