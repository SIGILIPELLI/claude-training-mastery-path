# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: understand what Claude actually is and isn't, get comfortable writing
clear and specific prompts, learn to structure a multi-turn conversation, and
apply Claude to real writing, analysis, and code-adjacent tasks — while
building the habit of checking its work.

6. [Using Claude for Code-Adjacent Tasks](06-code-adjacent-tasks.md)

9. [Understanding Limitations & Verifying Outputs](09-limitations-and-verification.md)
10. [Project — Build a Personal Prompt Template Library](10-project-prompt-template-library.md)

By the end of this level you'll be able to write clear, specific prompts,
carry a productive multi-turn conversation, use Claude for real writing,
research, and code-adjacent work, hand it documents effectively, iterate on
its output like a first draft rather than a final answer, and know when to
double-check what it tells you.
