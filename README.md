# Claude Training Mastery Path

A free, structured, module-wise training program on using Claude, Anthropic's
AI assistant, effectively — entry level to master level, with worked prompt
examples and a hands-on deliverable at the end of each level.

This is an independent educational resource, not an official Anthropic
publication.

**Live site:** https://sigilipelli.github.io/claude-training-mastery-path/

## Contents

- **Level 1 · Entry** — what Claude is, writing effective prompts, structuring conversations, core use cases
- **Level 2 · Intermediate** — advanced prompting, structured outputs, brainstorming, fact-checking workflows
- **Level 3 · Advanced** — context management, multi-step workflows, team usage, privacy considerations
- **Level 4 · Master** — organizational AI literacy, governance, training others, career growth

## Local development

python3 -m venv .venv
